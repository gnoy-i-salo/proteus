PROTEUS 0.1.2

- Возвращены блоки журнала этапов со встроенными трейсами; селект персоны/этапа удалён. Боковая панель переключает логи и результаты выбранной персоны.
- Крупный BSC теперь показывает метрику выбранной персоны. Общее отношение двух BSC подписано отдельно. Проверена независимость входных данных, архетипов, ответов и времени расчёта; формула не изменена.
- Импорт и экспорт `.proteus` v1: имена, публичные ссылки, контекст двух персон и общая задача. Системные диалоги и открытие через файловый менеджер; импорт во время эксперимента откладывается. Файл не запускает модели автоматически.
- Пагинация полей сохраняет исходные пробелы и переносы при импорте и экспорте.

Локально пройдены 39 unit-тестов, 20 браузерных сценариев, Rust-проверки и нативная сборка. На macOS проверены открытие файла при запуске, повторное открытие через Finder и экспорт через системный диалог с точным совпадением данных.

Приложение использует отдельно установленные и авторизованные Codex / Kimi CLI.

- macOS Apple Silicon: `macos-arm64.dmg`; Mac Intel: `macos-x64.dmg`.
- Windows x64: установщик `.exe`.
- Linux x64 (Ubuntu 24.04 и совместимые): пакет `.deb`.
- `SHA256SUMS.txt` содержит контрольные суммы установщиков.

Сборка macOS подписана ad-hoc, без Apple notarization; Windows — без сертификата издателя. ОС может запросить разрешение на запуск. Эксперименты и настройки хранятся отдельно от приложения и сохраняются при обновлении.
