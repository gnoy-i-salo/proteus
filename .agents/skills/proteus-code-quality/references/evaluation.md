# Evaluation cases

Run these as scoped review exercises against the current repository or an isolated fixture. Do not call providers or write account data. Judge the resulting ownership and behavior, not whether the agent repeats headings. Re-run against the final combined tree before closing the quality epic.

| Request                                                  | Observable successful outcome                                                                                                                             | Reject                                                                                         |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Extract the ConnectionsPanel polling lifecycle           | Slice model owns timer/revision/disposal; reactive getters survive selection changes; late response cannot overwrite new state; cleanup and e2e preserved | Global store, snapshot of changing prop, missing cleanup, unchanged giant controller           |
| Split Person Fabric's evidence parser from orchestration | Local parser and explicit public exports; task-free baseline and evidence constraints unchanged; dependent tests pass                                     | New npm package, lost source text, task leakage, tests only asserting file count               |
| Rename a native own DTO field to `pollAfterMs`           | Rust field remains `poll_after_ms`; explicit TS/Rust wire fixture; supported legacy data still decodes                                                    | Rename OAuth `access_token`, expose secret, omit compatibility version                         |
| Convert `model-settings__row--active`                    | Base `modelSettings__row` and modifier `modelSettings__row_active` assigned together; selectors/references/tokens/checks agree                            | Modifier only, `--active`, replacement of CSS properties or user strings                       |
| Read legacy result/preset with exact quotes              | Known schema decoder, unchanged Unicode/whitespace/IDs, explicit unknown version/collision/oversize failure                                               | Generic recursive rename, alias collision silently accepted, invented historical result reader |
| Simplify a one-line pure helper                          | Keep it with its owner unless independent responsibility warrants extraction                                                                              | New layer/type hierarchy merely to shorten file                                                |

Mechanical validation checks frontmatter, name and scaffolding; it does not establish these behavioral outcomes. Report commands actually run and any untested cases. Product fixes require their own regression tests, not only these review exercises.
