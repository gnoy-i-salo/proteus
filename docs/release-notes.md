Приложение использует отдельно установленные и авторизованные Codex / Kimi CLI.

- macOS Apple Silicon: `macos-arm64.dmg`; Mac Intel: `macos-x64.dmg`.
- Windows x64: установщик `.exe`.
- Linux x64 (Ubuntu 24.04 и совместимые): пакет `.deb`.
- `SHA256SUMS.txt` содержит контрольные суммы установщиков.

Сборка macOS подписана ad-hoc, без Apple notarization; Windows — без сертификата издателя. ОС может запросить разрешение на запуск. Эксперименты и настройки хранятся отдельно от приложения и сохраняются при обновлении.
