# Handoff: подключённые источники и релиз 0.3

`bd` отсутствует в рабочем окружении. Beads не синхронизирован, задачи не созданы и не закрыты; существующий `.beads/issues.jsonl` не заменён фиктивными записями.

Объём изменения: четыре bundled skills, native SourcePort и авторизация, настройки подключений и grants в desktop, отдельный анализ корпуса, стиль с provenance, точные реплики, очищенный экспорт schema 3, статическая TDLib и выпуск установщиков.

Релиз должен оставаться черновиком до проверки зарегистрированных приложений на реальных аккаунтах. OAuth/state/PKCE fixtures и browser IPC mocks не заменяют реальный вход. Для Telegram нужны пользовательские API ID/hash; VK и GitHub — Client ID; Instagram — поддерживаемый экспорт или токен собственного профессионального аккаунта. Секреты в handoff не записываются.

Обязательные проверки перед push: `pnpm check`, `pnpm test:e2e`, `pnpm check:rust`, `pnpm build:desktop`, `git diff --check`. CI дополнительно собирает нативные приложения каждой платформы и Pages. Результаты проверок и ссылка на черновик фиксируются в release notes после выполнения, а не предполагаются заранее.

Отдельные следующие задачи: живой smoke-test подключений с зарегистрированными приложениями, безопасный режим Kimi без пользовательских hooks, изолированный браузерный сбор, независимая оценка сходства на отложенных диалогах. Ни одна из этих возможностей не объявляется реализованной проверкой синтетических данных.

Подтверждено локально: полный JavaScript gate, 53 browser-сценария, production Pages artifact, точный `pnpm check:rust` с TDLib; после последнего refresh-fix — 47 Rust tests passed, один существующий live CLI test ignored. Вход с реальными аккаунтами не выполнялся.

Локальная release-сборка macOS Apple Silicon с встроенной TDLib и упаковка `.app` / `.dmg` прошли. Динамические зависимости бинарника — системные библиотеки macOS; отдельная установленная TDLib не требуется.
