# Выбранная публичная страница

`ingestion::selected_page::fetch` — нативный загрузчик одной явно выбранной страницы для
`proteus-tip.7`. Это слой получения исходника; подключение к durable ingestion, сохранение
снимка, извлечение читаемого текста HTML, назначение source binding и UI ещё не завершены.
Текущий загрузчик сам не вызывает модель, не обходит ссылки и не приписывает авторство
страницы владельцу сайта или выбранной Персоне.

Принимаются HTTP/HTTPS на стандартных портах, без встроенных учётных данных. Каждый
переход проверяется заново: не более пяти перенаправлений, без перехода с HTTPS на HTTP.
Проверка DNS отклоняет весь ответ, если хотя бы один адрес относится к локальным,
частным, служебным, документационным или неподдерживаемым диапазонам. IPv6 ограничен
глобальным unicast с исключением специальных и переходных диапазонов. Политика намеренно
консервативнее доступности отдельных специальных адресов. Используются
[реестр IPv4 IANA](https://www.iana.org/assignments/iana-ipv4-special-registry/) и
[реестр IPv6 IANA](https://www.iana.org/assignments/iana-ipv6-special-registry/).

Проверенные IP закрепляются в новом HTTP-клиенте для конкретного перехода с сохранением
имени сервера для TLS; адрес фактического соединения также проверяется. Автоматические
redirects, proxy, Referer и распаковка отключены. Нет cookies и заголовков авторизации,
нет обращения к хранилищам аккаунтов. Настройки клиента соответствуют API
[reqwest 0.12 blocking ClientBuilder](https://docs.rs/reqwest/0.12.28/reqwest/blocking/struct.ClientBuilder.html).

Размер ограничен максимумом 16 MiB, включая ответы без Content-Length или с ложным
значением; объявленный и фактический размеры должны совпасть. Принимается только полный
ответ 200 с `text/html`, `text/plain` или `text/markdown` и UTF-8. Неизвестная кодировка,
сжатие, частичный ответ, HTTP-ошибка и повреждённый UTF-8 завершаются явной ошибкой.
Исходные UTF-8 байты, пробелы, CRLF, Unicode и HTML сохраняются без нормализации. SHA256
вычисляется по этим байтам; снимок содержит исходный выбранный URL, конечный URL, цепочку
перенаправлений и время получения. Фрагменты URL не отправляются серверу. HTML нельзя
непосредственно вставлять в интерфейс как разметку.

Бюджет одного получения — до 60 секунд, охватывает разрешение имени, переходы и чтение.
Текущий остаток передаётся сетевому клиенту, проверяется до/после I/O и перед возвратом
результата. Отмена кооперативная: уже ожидающий сетевой вызов не прерывается мгновенно;
просроченный или отменённый результат не возвращается. Системный DNS не имеет переносимой
принудительной отмены: ожидание ограничено, одновременно допускаются не более двух
DNS-работников, и просроченный работник удерживает слот до своего завершения.

Проверка grant, разрешения на модельную обработку и export остаётся обязанностью сценария,
который будет сохранять и использовать снимок. Этот транспорт не выдаёт grant и не заменяет
проверку прав. Для login-only страниц предусмотрен отдельный импорт; данный загрузчик не
использует активную браузерную сессию. Модельные и личные архивы в тесты не передаются.

Синтетические тесты покрывают ограничения адресов и mixed DNS, повторную проверку после
redirect, смену DNS-ответа, предел переходов, ложный размер, тип/кодировку/status,
сохранение точного текста и происхождения, отмену после DNS и во время чтения, общий
deadline. Они не являются живой проверкой произвольных сайтов или завершением задачи
`proteus-tip.7`.
